What is RAG?
Retrieval-Augmented Generation
Instead of relying on the LLM's memorised weights, RAG retrieves relevant facts first, then asks the LLM to answer using only those facts — dramatically reducing hallucination.
❓
Question
User asks a natural-language question
→
🔍
Retrieve
Search the Knowledge Base for relevant facts
→
📎
Augment
Combine retrieved facts with the question into a grounded prompt
→
🤖
Generate
LLM produces an answer grounded in the retrieved context
→
✅
Answer
Grounded response with citations — not a guess
🗄️
Knowledge Base
The structured store of verified facts (graph + vectors) that the Retrieve step searches. The quality of every answer is bounded by the quality of this KB.
Key insight — The LLM is just the interface. The Knowledge Base is the source of truth. A good KB + a weak LLM beats a strong LLM with no KB.
