What are LLMs?
The Prediction Pipeline
An LLM takes a prompt, flows it through layers of attention, and predicts the next word — then feeds that word back in to predict the next, one token at a time.
word 2 / 10
Key insight — Each predicted word is fed back as input for the next prediction. The model never "looks up" facts — it generates statistically likely continuations, which is why grounding in a knowledge base matters.
