Language & multilingual considerations
Key rule: multilingual embeddings (mE5, LaBSE, text-embedding-3-large) map different languages into shared vector neighbourhoods automatically. Knowledge graph labels, relational columns, and document fields do NOT — every entity name must be stored explicitly per language, or cross-lingual matching fails.
