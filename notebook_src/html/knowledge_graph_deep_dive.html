Language & multilingual considerations
Key rule: multilingual embeddings (mE5, LaBSE, text-embedding-3-large) map different languages into shared vector neighbourhoods automatically. Knowledge graph labels and literals do NOT — every entity name must be stored explicitly per language. A graph node for "Paris" needs separate rdfs:label entries for French, English, German, etc., or cross-lingual entity linking will fail.
