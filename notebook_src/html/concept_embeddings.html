What are Embeddings?
Numbers that capture meaning
An embedding model encodes any piece of text as a dense vector of numbers. The key property: semantically similar texts produce geometrically nearby vectors.
"Goldfish have a three-second memory."
→
Encoder model
→
[0.12, −0.34, 0.87, …] × 384 values
2D semantic space — similar meanings cluster together
Key insight — Cosine similarity between two vectors measures how semantically close they are (1.0 = identical meaning, 0 = unrelated, −1 = opposite). This is what powers semantic search: encode the query, find the nearest vectors.
