Exploring Embedding Space
Explore how words cluster by meaning in vector space, see vector arithmetic in action, and compare cosine similarity between words.
Vector arithmetic works because direction encodes meaning — "royalty" and "gender" are learnable directions in the space.
king − man + woman ≈ queen
Paris − France + Germany ≈ Berlin
walking − walk + swim ≈ swimming
Visualised below: the "royalty" direction (king→queen, prince→princess) and "gender" direction are roughly parallel — the model has learned these as geometric relationships, not explicit rules.
Select a word to see its cosine similarity to all others. Cosine similarity measures the angle between vectors — 1.0 = identical direction, 0 = unrelated, negative = opposite meaning.
Static embeddings (Word2Vec, GloVe) give a word exactly one vector, forever. Transformer models compute a new vector every time from the surrounding words — the same word gets a different vector in every sentence. Select a sentence below and watch "bank" relocate.
